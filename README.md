Financial Risk Assessment and Loan Default Prediction
This project analyzes loan data to predict which customers may default on their loans using Excel.
What I Did:Cleaned and prepared loan data using Power QueryCreated Pivot Tables and Pivot Charts for analysisBuilt an interactive Dashboard with SlicersKey 
Insights:Loan Default Rate by Age, Income, Loan TypeHigh Risk Customers IdentificationCredit Score vs Default RelationshipCity-wise and Employment-wise
Risk AnalysisTools Used: Microsoft Excel, Power Query, Pivot Tables, Dashboard
Who is Benefited:Banks and Financial Institutions can predict loan defaulters and reduce financial risk.Loan Officers can easily decide to approve or reject a loan.
