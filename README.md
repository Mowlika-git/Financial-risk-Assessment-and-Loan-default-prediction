Financial Risk Assessment and Loan Default Prediction

This project analyzes loan data to predict which customers may default on their loans using Excel.

What I Did:
- Cleaned and prepared loan data using Power Query
- Created Pivot Tables and Pivot Charts for analysis
- Built an interactive Dashboard with Slicers

 Key Insights:
- Loan Default Rate by Age, Income, Loan Type
- High Risk Customers Identification
- Credit Score vs Default Relationship

Tools Used:
Microsoft Excel, Power Query, Pivot Tables, Dashboard

Who is Benefited:
Banks and Financial Institutions can predict loan defaulters and reduce financial risk.
